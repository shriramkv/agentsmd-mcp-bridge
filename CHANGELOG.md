# Changelog

All notable changes to this project are documented here. The format is based on
Keep a Changelog, and this project adheres to Semantic Versioning.

## [0.1.0] - 2026-07-07

### Added
- `generate-mcp`: generate a Model Context Protocol server from an AGENTS.md file.
- `generate-agentsmd`: generate an AGENTS.md section from an MCP tool manifest.
- `list-commands`: list the commands extracted from an AGENTS.md file.
- Dependency-free core parser and extractor with a curated command allow-list.
- Test suite (31 tests, 98% coverage) and CI across Python 3.10 to 3.13.
